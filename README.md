# GetFang.com

Contains [the website](https://getfang.com/) for the [Fang newsreader.](https://github.com/MrEricSir/Fang)

Both the downloads/changelogs on the website and Fang the [update RSS feed](https://getfang.com/feed.xml) are built automatically from the data in [releases.yml](https://github.com/MrEricSir/fang-website/blob/main/_data/releases.yml)
